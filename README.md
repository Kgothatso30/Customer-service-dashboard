# 📱 Telecom Customer Service Analytics Dashboard

## 📋 Project Overview

This project is an interactive **Telecom Customer Service Analytics Dashboard** designed to help telecom companies understand customer behavior, revenue patterns, and support effectiveness.

**The Problem:** Telecom companies struggle to identify at-risk customers, optimize support resources, and understand payment preferences.

**The Solution:** A comprehensive dashboard providing customer segmentation analysis, revenue tracking, churn risk monitoring, and support ticket analysis.

---

## 📊 Key Metrics

| Metric | Value |
|--------|-------|
| **Total Customers** | 5,000 |
| **Monthly Revenue** | R383,391+ |
| **Average Churn Risk** | 28.6% |
| **Customer Satisfaction** | 3.69 / 5.0 |

---

## 🔍 Key Insights

| Insight | Finding |
|---------|---------|
| **Revenue Distribution** | Premium and Business segments drive 60%+ of revenue |
| **Churn Risk** | Basic segment has highest churn risk |
| **Payment Preference** | Credit Card and Debit Card are most popular |
| **Support Impact** | Higher support tickets correlate with lower satisfaction |
